# 📊 Data Cleaning & Visualization Project

## 🛒 SuperStore Sales Analysis

A complete data cleaning, analysis, and visualization project using Python and the SuperStore sales dataset.

The project demonstrates the complete data analysis workflow:

**Raw Data → Data Cleaning → Exploratory Data Analysis → Visualization → Business Insights**

---

## 🎯 Project Objectives

- Explore a raw SuperStore sales dataset
- Identify and handle missing values
- Check and remove duplicate records
- Convert columns into appropriate data types
- Detect and handle outliers
- Analyze sales, profit, quantity, category, and regional performance
- Create meaningful data visualizations
- Extract useful business insights

---

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 📈 Seaborn
- 📓 Jupyter Notebook
- 🐙 Git & GitHub
